# Quick Access — Tab Baru

## Cara pasang (pertama kali)

1. Buka Chrome (profil **Nur**) dan ketik `chrome://extensions`.
2. Pastikan **Developer mode** (kanan atas) aktif.
3. Klik **Load unpacked**, lalu pilih folder `D:\coding\quick-access-newtab\quick-access`.
4. Buka tab baru (`Ctrl+T`). Jika Chrome bertanya "Change back to Google?", pilih **Keep it**.

Jangan pindahkan atau hapus folder ini, karena Chrome membacanya langsung dari sini.

## Cara memperbarui (setelah ada fitur baru)

1. Buka `chrome://extensions`.
2. Di kartu **Quick Access — Tab Baru**, klik ikon ↻ (**Reload**).
3. Tutup lalu buka lagi tab barunya.

## Buka otomatis saat Chrome dijalankan

1. Ketik `chrome://settings/onStartup`.
2. Pilih **Open the New Tab page**. Pengaturan ini juga menghapus `localhost:7575`.

## Fitur

**Shortcut**
- **Tambah**: klik kotak **+ Tambah**, lalu pilih *Shortcut* atau *Folder*. Untuk aplikasi gunakan link khusus, misalnya `steam://open/main`, `vscode://`, `spotify:`, atau `ms-settings:`.
- **Edit/hapus**: klik kanan shortcut atau klik tombol **⋯**. Setelah menghapus, tekan `Ctrl+Z` untuk membatalkan.
- **Folder**: seret shortcut ke atas folder untuk memasukkannya. Klik folder untuk membukanya, mengganti namanya, atau membuka semua isinya.
- **Atur urutan**: seret shortcut ke posisi baru, atau ke tab grup lain untuk memindahkannya.
- **⧉ Buka semua**: membuka semua link web di grup yang sedang aktif sebagai tab baru.
- **🔥 Sering**: grup ini muncul otomatis dan berisi shortcut yang paling sering kamu klik.
- **Impor bookmark**: buka Pengaturan → Data → *Impor bookmark Chrome*. Folder bookmark menjadi grup, dan sub-foldernya menjadi folder.

**Pencarian & terjemah**
- Saat kamu mengetik, riwayat dan bookmark Chrome yang cocok muncul. Pilih dengan `↑`/`↓`, lalu tekan `Enter`.
- Tombol **🔍 Google / 🌐 Terjemah** di kotak pencarian memilih antara mencari di web atau menerjemahkan.
- Di mode **Terjemah**, cukup ketik. Terjemahannya langsung muncul di bawah kotak pencarian. Bahasa asal dideteksi otomatis: kalau kamu mengetik dalam bahasa Indonesia, hasilnya bahasa Inggris, dan sebaliknya. Pilih bahasa lain (Arab, Jepang, Korea, Mandarin, Jawa, Sunda, dan lain-lain) dari menu di kanan kotak pencarian.
- Di panel terjemahan ada **⇄** untuk menukar arah, **🔊 Dengarkan**, **Salin**, dan **Google Translate ↗**. Untuk satu kata, arti lainnya juga ditampilkan.
- `Shift+Enter` di mode Terjemah tetap mencari di Google.
**Musik (YouTube)**
- Putar lagu di **YouTube** atau **YouTube Music**. Widget Musik akan menampilkan judul, artis, sampul, dan progres lagu.
- Tombol ⏮ ⏯ ⏭ mengontrol tab YouTube-nya: lagu sebelumnya, putar/jeda, dan lagu berikutnya. Klik bar progres untuk lompat ke bagian tertentu, atau ↗ untuk membuka tab YouTube-nya.
- ⏮ bekerja seperti pemutar musik: jika lagu sudah berjalan lebih dari 5 detik, lagu diulang dari awal; tekan sekali lagi untuk kembali ke lagu sebelumnya.
- Setelah ekstensi di-reload, tab YouTube yang sudah terbuka akan dicari dan disambungkan otomatis setiap kali kamu membuka tab baru.
- Kalau widget menampilkan **🔒 Izinkan akses YouTube**, klik tombolnya. Itu artinya ekstensi belum di-reload setelah update; cara lainnya: buka `chrome://extensions` lalu klik ↻ Reload.
- Kalau widget menampilkan **🔌 Sambungkan**, klik tombolnya atau pilih *Muat ulang tab YouTube*.
- Baris kedua: **🔊 volume** (geser), **🔁 ulangi** (🔂 = ulangi satu lagu), **🔀 acak** (YouTube Music atau playlist), **📜 lirik**, dan **☰ lagu berikutnya**.
- **📜 Lirik** mengikuti lagu baris demi baris (sumber lrclib.net). Klik satu baris untuk lompat ke bagian itu. Tidak semua lagu ada liriknya.
- **☰ Berikutnya** menampilkan antrean YouTube Music, isi playlist YouTube, atau saran video berikutnya. Klik untuk langsung memutarnya.
- **Visualizer** (Pengaturan → Tema & wallpaper): gelombang di bawah layar yang mengikuti irama lagu. Kalau gelombangnya belum bergerak sesuai irama, klik sekali di tab YouTube-nya. Selama itu, gelombang lembut tetap tampil saat lagu diputar.

**Peliharaan**
- Ada hewan kecil yang hidup di halaman tab baru. Dia berjalan, duduk, tidur (lebih sering di malam hari), berjoget kalau ada musik YouTube yang diputar, dan sesekali bicara (misalnya mengingatkan waktu sholat atau menyemangatimu saat Pomodoro). Dia bisa berdiri dan berjalan di atas kartu widget.
- **Klik** = senang dan melompat · **tahan** = dielus · **seret** = diangkat · **seret lalu lepas sambil digerakkan** = dilempar · **klik dua kali** = salto · **klik kanan** = menu (camilan, main bola, tidur) · klik 5× cepat = pusing 😵.
- **Status**: arahkan kursor ke peliharaan untuk melihat bar 🍖 kenyang, 💗 senang, dan ⚡ energi. Kalau lama tidak diberi makan, dia sedih dan minta camilan. Kalau energinya habis, dia lebih sering tidur. Bar langsung muncul kalau ada yang hampir habis.
- **Level & aksesori**: setiap kali diajak main, dielus, diberi makan, atau mengambil bola, XP-nya bertambah. Saat naik level, aksesori baru terbuka: 🎀 pita (Lv 2), 👓 kacamata (3), 🧣 syal (4), 🥳 topi pesta (5), 🌸 bunga (6), 🎧 headphone (7), 👑 mahkota (8). Pilih aksesorinya di Pengaturan → Peliharaan.
- **🎾 Main bola**: klik kanan peliharaan → *Main bola*, atau tombol di Pengaturan. Bola juga bisa kamu seret dan lempar sendiri. Peliharaan mengejar bola, melompat kalau bolanya di atas widget, lalu membawanya kembali.
- **Reaksi**: semua tugas selesai → dia tepuk tangan 🎉; Pomodoro mulai → dia menemanimu fokus; waktu istirahat → dia ikut tidur.
- **Peliharaan kedua**: nyalakan di Pengaturan → Peliharaan. Keduanya saling menyapa, bermain, dan berebut bola.
- Atur jenis (Kucing, Anjing, Kelinci, Panda, Anak ayam, Slime), nama, ukuran, tingkah laku, balon bicara, dan suara di Pengaturan → **Peliharaan**.
**Widget**
- **Ayat harian**: satu ayat baru setiap hari di bawah jam. Klik ayatnya untuk menampilkan teks Arab.
- **Jadwal sholat & kiblat**: memakai metode Kemenag RI, dan menampilkan arah kiblat dari kotamu.
- **Notifikasi azan**: muncul saat masuk waktu sholat, juga ketika tab baru sedang tidak dibuka. Bisa dimatikan per waktu sholat, diatur agar mengingatkan 5/10/15 menit sebelumnya, dan memakai file MP3 azan milikmu sendiri.
- **Pomodoro**: 25 menit fokus dan 5 menit istirahat, plus istirahat panjang setiap 4 sesi. Notifikasi dan suara muncul walaupun tab sudah ditutup.
- **Kalender**: tanggal Masehi dan Hijriah, plus libur nasional (merah). Tanggal hari besar Islam masih perkiraan dan bisa berbeda 1 hari dengan ketetapan pemerintah.
- **Hitung mundur**: menuju tanggal penting, ditambah info libur berikutnya.
- **Pengingat**: sekali, setiap hari, atau berulang (misalnya tiap 1 jam, hanya antara jam 08–21).
- **Tugas** dan **Catatan**.
- **🔐 Kunci catatan**: klik 🔐 di kartu Catatan untuk memasang PIN (4–8 angka). Isinya disimpan terenkripsi (AES-256). Klik 🔓 untuk mengunci lagi, mengganti PIN, atau menghapus PIN. **Kalau PIN lupa, catatan tidak bisa dibuka**; pilihannya hanya menghapus catatan itu.

Semua widget bisa disembunyikan lewat Pengaturan → *Tampilkan*.

**Tata letak**

Seluruh halaman adalah papan grid bebas. Setiap bagian (jam, ayat, kotak pencarian, shortcut, dan semua widget) adalah blok yang bisa dipindah dan diubah ukurannya.

Klik ikon tata letak (di sebelah kiri ⚙ di pojok kanan atas), atau buka Pengaturan → *Atur tata letak*. Setelah itu:
- **Seret blok ke mana saja**: atas, bawah, kiri, kanan, atau tengah. Bayangan ungu menunjukkan tempat blok akan mendarat, dan blok lain yang tertabrak otomatis bergeser ke bawah.
- **Tarik sudut kanan bawah** (segitiga ungu) untuk mengubah lebar dan tinggi blok.
- **Jam membesar atau mengecil** mengikuti ukuran kotaknya.
- **↕ Tinggi otomatis**: kalau menyala, tinggi blok mengikuti isinya. Setelah kamu menarik ukurannya sendiri, mode ini mati; klik ↕ untuk menyalakannya lagi.
- **👁** menyembunyikan blok. Blok yang tersembunyi muncul di toolbar bawah; klik untuk menampilkannya lagi.
- **⇡ Rapikan** menaikkan semua blok untuk menutup ruang kosong.
- **Reset tata letak** mengembalikan semuanya ke susunan awal.
- **Ikon shortcut** S/M/L dan **garis bantu** bisa diatur di toolbar.

**Template & susunan tersimpan**
- Klik ikon tata letak di pojok kanan atas untuk membuka menu: pilih **template** atau **susunan tersimpan** dengan sekali klik.
- Template bawaan: 🏠 **Klasik**, 🤍 **Minimalis** (jam besar, pencarian, shortcut), 📊 **Dashboard** (semua widget), 💼 **Kerja** (Pomodoro, tugas, catatan, musik), 🕌 **Ibadah** (sholat, ayat, kalender Hijriah), ⚖️ **Simetris**.
- **💾 Simpan susunan** (di toolbar mode atur) menyimpan tata letakmu sekarang dengan nama, misalnya "Kerja", "Santai", atau "Ramadan". Klik namanya untuk memakai, klik kanan untuk mengganti nama, ✕ untuk menghapus.
- **↶ Batalkan** mengembalikan tata letak sebelum kamu memakai template atau susunan lain.

**🎯 Mode fokus**: tombol 🎯 di pojok kanan atas menyembunyikan semuanya kecuali jam, pencarian, dan Pomodoro. Klik lagi atau tekan `Esc` untuk keluar. Tata letakmu tidak berubah.
Tekan **Selesai** atau `Esc` untuk menyimpan. Di jendela yang sangat sempit (di bawah ±760px), blok ditumpuk ke bawah dan tata letak tidak bisa diatur sampai jendelanya diperbesar.

## Tema

Buka Pengaturan → **Tema & wallpaper**:
- **Rekomendasi tema** mengatur wallpaper dan warna sekaligus: 🔮 Aurora Klasik, 🌌 Malam Tenang, 🌅 Senja Hangat, 🌊 Fokus Biru, 🌿 Zen Hutan, 🌸 Sakura, ☕ Kopi Pagi, 🕌 Ramadan (dengan jam analog), 🌄 Fajar, 💜 Lavender, 🌤️ Langit Cerah.
- **Tema otomatis sesuai waktu**: pagi (05–10) ☕ Kopi Pagi · siang (10–15) 🌊 Fokus Biru · sore (15–18) 🌅 Senja Hangat · malam 🌌 Malam Tenang. Memilih tema sendiri akan mematikan mode otomatis.
- **Efek cuaca di latar** mengikuti cuaca kotamu: hujan, petir, salju, kabut, atau bintang (dengan bintang jatuh) di malam yang cerah.

Saran kombinasi:
- **Kerja di siang hari**: template 💼 Kerja + tema 🌊 Fokus Biru + mode 🎯 Fokus saat butuh konsentrasi.
- **Santai di malam hari**: template ⚖️ Simetris + tema 🌌 Malam Tenang + visualizer musik + lirik.
- **Ramadan**: template 🕌 Ibadah + tema 🕌 Ramadan + notifikasi azan + hitung mundur ke Lebaran.
- **Minimalis**: template 🤍 Minimalis + tema 💜 Lavender + ukuran ikon shortcut L.
## Pengaturan

Pengaturan (ikon ⚙ di pojok kanan atas) dibagi menjadi 7 tab: **🎨 Tampilan · 🧩 Widget · 🔎 Pencarian · 🕌 Ibadah · ⏱ Fokus · 🐱 Peliharaan · ⚙️ Umum**. Bingung mencari sesuatu? Ketik saja di kotak **"Cari pengaturan…"**, misalnya *font*, *azan*, *wallpaper*, atau *sticky*.

**Semua fitur tambahan di bawah ini mati sampai kamu menyalakannya.** Pakai yang kamu suka, abaikan yang tidak.

## Fitur tambahan (opsional)

**🎨 Tampilan** (tab Tampilan)
- **📷 Foto harian otomatis**: wallpaper foto pemandangan baru setiap hari (dari Bing). Di pojok kiri bawah layar ada 🤍 untuk menyimpan foto ke favorit dan ⟳ untuk foto hari-hari sebelumnya. Bisa juga diatur untuk mengacak foto dari favoritmu saja.
- **Wallpaper bergerak**: *Gradien* (warna bergeser pelan), *Partikel* (bulatan cahaya melayang), atau *Video* (unggah MP4 milikmu sendiri, maks 60 MB).
- **Gaya kartu widget**: Kaca, Solid, Garis, atau Neon. Atur juga transparansi dan bulatnya sudut.
- **Font**: Outfit, Poppins, Nunito, Fredoka (bulat & imut), Playfair (elegan), atau JetBrains Mono.
- **Jam**: Digital, Analog, **Flip** (angka membalik seperti jam stasiun), **Neon** (menyala), atau **Kata** ("jam setengah sepuluh malam").
- **Dekorasi musiman**: otomatis sesuai tanggal. Lampion dan bulan saat Ramadan, ketupat saat Lebaran dan Idul Adha, bendera merah putih menjelang 17 Agustus, salju saat Natal, konfeti saat Tahun Baru. Peliharaan ikut memakai kostum (peci, ikat kepala merah putih, topi Santa, topi pesta) kalau belum memakai aksesori. Bisa juga dipilih manual atau dimatikan.
- **Efek kursor**: percikan bintang saat mengklik, atau jejak bintang yang mengikuti kursor.

**⌨️ Palet perintah: `Ctrl+K`** (atau tombol ⌘K di pojok kanan atas)
- Satu kotak untuk apa saja: buka shortcut, pindah grup, ganti tema atau tata letak, mulai/jeda Pomodoro, mode fokus, buka bagian pengaturan, panggil atau beri makan peliharaan.
- Ketik teks bebas untuk mencarinya di Google, menerjemahkannya, menjadikannya tugas, atau sticky note. Ketik hitungan, hasilnya langsung muncul.

**🧮 Kalkulator & konversi** (di kotak pencarian, menyala bawaan; matikan di tab Pencarian)
- Hitungan: `12*5+3`, `(2+3)^2`, `15% * 200`, `sqrt(144)`. Tekan Enter untuk menyalin hasilnya.
- Satuan: `5 km ke mil`, `30 c ke f`, `1 kg ke lb`, `2 jam ke menit`, `500 mb ke gb`, `100 kmh ke mph`.
- Kurs langsung: `10 usd ke idr`, `1 sar ke idr`, `100 jpy ke idr` (20 mata uang).

**📝 Sticky notes** (tab Widget → Opsi widget, atau tombol 📝 di pojok kanan atas)
- Kertas tempel yang bisa ditaruh di mana saja: seret dari bagian atasnya, ubah ukurannya dari sudut kanan bawah, pilih warnanya dari titik warna yang muncul saat kursor diarahkan, dan hapus dengan ✕.

**🧩 Widget baru** (nyalakan di tab Widget → Tampilkan, lalu atur posisinya seperti widget lain)
- **Kebiasaan harian**: centang setiap hari, 7 hari terakhir terlihat, lengkap dengan hitungan 🔥 hari beruntun. Ada saran seperti Sholat 5 waktu, Baca Qur'an, dan Olahraga. Klik kanan nama kebiasaan untuk menghapusnya.
- **Statistik fokus**: grafik sesi Pomodoro 7 hari, total jam fokus, hari beruntun, dan rekor.
- **Mood harian**: pilih emoji perasaanmu. Ada kalender mood sebulan, dan peliharaan ikut merespons.
- **Kurs & harga emas**: USD, SGD, MYR, SAR, EUR, dan JPY ke Rupiah, ditambah harga emas dunia per gram (harga spot, bukan harga toko atau Antam).
- **Suara latar**: hujan, ombak, angin, api unggun, burung, brown noise, dan lo-fi. Bisa dicampur dengan volume masing-masing. Semua suara dibuat langsung di browser, jadi tidak perlu file. Suara berhenti kalau tab ditutup.
- **Cuaca lengkap** (tab Widget → Opsi widget): grafik suhu 12 jam, prakiraan 7 hari, dan kualitas udara (AQI & PM2.5).

**⟳ Sinkron antar perangkat** (tab Umum → Sinkron & data)
- Shortcut, tugas, kebiasaan, catatan, dan pengaturan ikut ke Chrome di laptop lain yang memakai akun Google yang sama. Tata letak, wallpaper sendiri, video, dan file azan tidak ikut, karena tiap layar bisa berbeda.
- Batas dari Chrome sekitar 100 KB, cukup untuk ratusan shortcut.
## Kalau notifikasi tidak muncul

- Pastikan **Focus assist / Do not disturb** Windows tidak aktif.
- Buka **Windows Settings → System → Notifications** dan pastikan **Google Chrome** diizinkan.
- Notifikasi hanya jalan selama Chrome terbuka. Chrome boleh berjalan di latar belakang, yaitu saat ikonnya ada di system tray.
- Gunakan tombol **Tes** di Pengaturan untuk mencobanya.

## Pintasan keyboard

| Tombol | Fungsi |
|---|---|
| `Ctrl` + `K` | Palet perintah (cari apa saja) |
| `/` | Fokus ke pencarian |
| `1`–`9` | Buka shortcut ke-1 s/d 9 |
| `Alt` + `←` / `→` | Pindah grup |
| `↑` / `↓` | Pilih saran riwayat/bookmark |
| `Enter` | Buka shortcut yang cocok, atau cari di web |
| `Shift` + `Enter` | Selalu cari di web |
| `Esc` | Keluar dari mode fokus / tutup terjemahan |
| `Ctrl` + `Enter` | Buka di tab baru |
| `!y`, `!gh`, `!w`, `!m`, `!tr` | Cari di YouTube, GitHub, Wikipedia, Maps, Google Terjemahan |

- Ayat: AlQuran Cloud (terjemahan Kemenag)
- Ikon situs: layanan favicon Google dan Chrome
- Terjemahan: Google Translate (tanpa API key)
